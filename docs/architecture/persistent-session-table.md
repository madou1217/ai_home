# 持久会话列表的列（aih ss / aih ss --list）

> 2026-10-31。实现：`lib/cli/services/ai-cli/session-table.js`；
> 列表与 picker 共用同一套列宽计算，所以两处永远对齐。

## 列定义（顺序固定）

| # | 列 | 宽度 | 说明 |
|---|---|---|---|
| 1 | 状态 | 4 | `●` 在用 / `○` 空闲 |
| 2 | provider | 12 | `claude` / `codex` / `codebuddycn` …（= harness 侧的身份） |
| 3 | 账号 | 14 | `#1` / `#.aih-server`（AIH Server 档显示 `.aih-server`） |
| 4 | 会话名称 | 剩余宽度（最小 10） | agent 给的标题；没有就项目名；超长按显示宽度截断加 `…` |
| 5 | 会话ID | **完整 36**（窄屏依次 24 → 16 → 隐藏） | 有原生会话 id 用原生 id（UUID 全量显示）；只有 pane 名时显示完整 pane 名；窗口变窄才逐渐截断 |
| 6 | 项目 | 18（分组展示时隐藏） | 项目目录名 |

## 窗口缩放时的行为

按「理想 → 收缩」的顺序降级，**只降级、不换序**：

1. 宽度不够 → 先去掉「项目」（`--list` 本来就按项目分组，项目列是冗余的）；
2. 仍不够 → 会话ID 从 22 缩到 16，再不够则整列隐藏；
3. 仍不够 → 账号列从 14 缩到 10 / 8；
4. 仍不够 → provider 从 12 缩到 9 / 8；
5. 会话名称永远保留（最小 10），吃掉剩余宽度。

所以拉伸窗口时只有「会话名称」变长变短，其它列的位置和顺序不变。

## 选中之后能做什么（小命令）

| 键 | 动作 | 说明 |
|---|---|---|
| Enter | 进入会话 | attach 到 tmux/psmux pane |
| **c** | 复制会话ID | 有原生 id 复制原生 id；只有 pane 名时复制 pane 名 |
| **y** | 复制进入命令 | `aih <cli> <账号> resume <id>`；没有原生 id 时 `aih ss <名字>` |
| **d** | 看详情 | provider#账号 · 项目路径 · 会话ID（显示在提示行） |
| x | 关闭选中 | 先播**粒子消散**（5 帧 × 55ms），再真正关闭 |
| X | 关闭闲置 | 批量关闭，不播动画 |
| ↑/↓、j/k | 换行 | |
| q / Esc | 退出 | |

剪贴板走系统工具（pbcopy / clip / wl-copy / xclip / xsel），拿不到时把内容直接打在提示行里，
不会报错。

### 粒子消散（关闭动画）

`lib/cli/services/ai-cli/particle-dissolve.js`：把被关闭的那一行逐帧打散成 `· ˙ ∙ ✦ ✧ ⁺ ˚`，
每帧显示宽度与原文一致（中文按两列补空格），5 帧共 ~275ms，只覆盖该行（不整屏重绘）。

关闭条件：非 TTY、`TERM=dumb`、`--no-anim` 时不播动画，直接关闭。
两套 picker（同步 / 异步，macOS 默认走异步）都实现了动画，6 帧 × 55ms ≈ 330ms。

## 性能

| 操作 | 之前 | 现在 |
|---|---|---|
| `aih ss --list` | 5.3s（完整 CLI 组合根 1.3s + 逐 socket 问 tmux 3s + codex state-sqlite 标题解析） | **~0.3s** |
| `aih ss` 打开 picker | 同上 | 同上 |
| `aih ss --refresh` | — | ~2s（强制完整采集 + 标题解析） |
| 按键刷新（picker 内） | 每次按键 100ms+ 采集 | 1.5s 节流；播动画期间不采集 |

三个来源的优化：

1. `bin/ai-home.js` 给 `ss`/`sessions` 加了轻量入口（注册表里有会话时才生效，
   注册表为空 = 可能需要重启后恢复，仍然走完整 CLI）；
2. 默认跳过 codex 的 state-sqlite 标题解析（单 scope 实测 3s），标题改从
   `run/cache/complete/ss-rows.json` 缓存补；
3. 缓存 30 分钟 TTL，真实跑过一次 `aih ss` 就会写入。

## 边界

- 状态（`●`/`○`）来自 tmux 的实时采集；快速路径下这次采集仍然是实时的，只有**标题**可能是缓存。
- 窄屏（< 70）时没有会话ID列 —— 用 `aih ss --list` 拉宽终端，或直接按名称选择。
- 进入会话不受这些列影响：`aih ss <名字|前缀|项目描述>` 仍然走完整匹配。

## 1. 产品定位与不可妥协的体验

Lumen 是系统级复制与粘贴的增强层，由三个独立但共享数据的核心模块组成：

- **Orbit**：高频、全屏底边、无干扰卡片轨道。一个全局快捷键呼出，选中即粘贴，不需要打开管理界面。
- **Native Library**：低频深度管理，采用原生桌面工具的窗口结构、列表/图库和可调节预览区，而非 Web Dashboard。
- **Universal Quick Look**：文档、代码、图片、音乐、视频以及批量文件的内容级预览引擎，无需打开原始应用。

必须保留的产品辨识度：跨屏串联（非镜像）、纵向类型光点、复制来源、卡片移除与粒子消散、撤销与连续补位、光学玻璃材质、空间变形动画、统一的批量剪贴板语义、真实的内容预览。

设计方向为 macOS 原生空间感与高端光学材质（HarmonyOS 式高光、粒子与空间动效）的结合；跨平台统一品牌语言，但尊重系统窗口、键盘及辅助功能习惯。不要回退到厚重赛博朋克 HUD、霓虹描边、网页式大标题、卡片套卡片或冗余工具栏。

### 动画执行标准

- Hover/Press：140–220ms 的尺寸、亮度、背景反馈；不得用大幅位置跳动导致点击区域漂移。光点本体的尺寸是唯一焦点特效，休眠约 850ms 后还原。
- 页面与列表/图库/偏好设置：220–300ms 的层级揭示、位移或布局重排；选中、搜索与滚动上下文不丢失。不得模拟网页路由闪屏。
- 打开、关闭、最大化/还原、菜单、弹窗、筛选、空状态、错误、复制/固定/删除/撤销、媒体控制、文件内翻页/Sheet/源代码切换均必须有符合语义的反馈。关闭时先完成退场或可中断地反向恢复；禁止用一个统一淡入淡出替代所有状态。
- 正式版对跨窗口和共享元素采用可中断的物理动效。真实文字不被拉伸；使用快照/合成层和可控内容揭示；运动应能继承当前速度，避免反复输入积压。
- 原型不是全部路径已达到原生动效的证明。动画覆盖及 GPU 性能必须独立验收。

## 3. Orbit — 布局及交互规范

### 3.1 布局

- 无边框浮层贴合物理屏幕底边，横向铺满有效显示区域；建议默认高度约 240–300 DIP，随屏幕尺寸及可用空间适配。
- 浮层不挤压当前应用、不改变现有窗口尺寸；关闭不留常驻控件。系统任务栏、Dock、全屏应用、虚拟桌面以及多 DPI 须分别验证。
- 卡片的主要视觉区域用于真实内容缩略图；V10：页眉仅类型图标、类型/语言和时间；正文为内容；页脚仅来源与必要状态（固定、快捷序号）。同一标题、域名、类型不重复。图像/封面/色块优先，代码紧凑，文档优先缩略图；集合显示叠层封面，ZIP 显示内部目录摘要。删除按钮只在 hover / 键盘焦点时出现。无额外常驻工具栏。
- 唯一常驻导航例外是左侧类型光点。宽度约 38 DIP，所有屏幕共享一组，不在每块显示器重复绘制。
- HTML 顶部的 Orbit/App、屏幕布局选择、主题按钮属于**演示器**，不是正式 Orbit UI。正式产品自动识别屏幕，不提供 N 屏模式切换或 Mirror 选项。

### 3.2 Optical Dots 3.0（V10）

逻辑顺序固定，首项是全部；视觉窗口最多显示 5 个相邻光点，随当前类型纵向滑动，首尾不循环。全部不常驻置顶，滚回首项即可恢复。无内容的类型保留逻辑位置、降低亮度，仍可选中并显示空状态。默认只展示低亮点，不显示光环、连线或标签；进入光点热区、键盘聚焦或主动纵向切换时才唤醒。

| 从上到下 | 类型 | 包含内容 |
|---|---|---|
| 1 | 全部 | 原始剪贴板事件序列 |
| 2 | 文本 | 普通文本、富文本的可读表示 |
| 3 | 代码 | 已识别的代码或代码文件 |
| 4 | 链接 | URL |
| 5 | 图片 | 图片及同类型集合（原生目标） |
| 6 | 颜色 | HEX、RGB 等（原型展示 HEX） |
| 7 | 文档 | PDF、Word、Excel 等 |
| 8 | 音频 | 单首歌曲、纯音频集合 |
| 9 | 视频 | 单个视频、纯视频集合（原生目标） |
| 10 | 其他文件 | 压缩包、文件夹、未识别格式、混合文件集合 |

默认选中点仅略大、略亮，不能常亮强光。hover 仅提升点自身亮度/尺寸及显示临时类型名称与数量；指针在各点间移动时，点自身先变大后回落、邻点沿方向错峰缩放，但不自动筛选。实际切换时五点窗口连续滑动、旧焦点缩小、新焦点放大并回弹到选中尺寸；旧卡片与新卡片沿相反方向退入。禁止水波式圆环、扩散环、光尾、连线或额外几何图形。离开热区且无新输入约 900ms 后恢复低亮。不可见光点不可点击或 Tab 聚焦。类型切换不得关闭 Orbit 或误触粘贴。保持唯一全局类型状态；每类记录横向滚动位置，回到该类型时尽量恢复，若当前选择不可见则确保焦点可见。首尾不循环，防止意外跳转。连续滚轮/触控板输入需累积阈值，并保证一次有效手势对应合理的类别切换；HTML 采用 42px 累积阈值，实际产品应针对设备调校。

### 3.4 移除及撤销

移除按钮与卡片粘贴点击的事件必须隔离；删除记录不等于删除源文件，也不等于清空系统剪贴板。移除后保持当前分类；焦点优先转移到原索引的下一张，若无下一张则上一张，若无内容则显示空状态。撤销恢复原全局序列中的位置；当前筛选不匹配时只更新资料库与分类数量，不强行展示不属于该类的卡片。撤销可连续进行。移除提示为临时浮动提示，不新增永久工具栏。

## 4. 多屏串联 — 不允许退化为 Mirror

| 拓扑 | 期望 |
|---|---|
| 单屏 | 全宽底部一条轨道 |
| 2/3/N 屏水平相邻 | 从左至右连续分布，允许卡片跨越屏幕边界 |
| 上下排列 | 默认仅底部显示器有浮层 |
| 2×2 或更多矩阵 | 最下方一排相邻显示器串联，上排不显示 |
| 不规则、错位、不同 DPI | 自动基于显示器坐标计算底部外露边缘及连续区；不得绘制到不存在的区域 |

推荐实现：每个参与显示器创建一个原生透明无边框浮层窗口，但所有窗口只渲染同一逻辑轨道对应的裁切区域。全局 `scrollOffset`、`typeFilter`、`selectedClipId`、动画时间轴和数据源唯一，不能每个窗口独立复制 DOM/卡片列表的完整内容。

正式开发先定义非规则拓扑策略（底边不共线、垂直偏移、间隔、旋转）：优先选择物理布局下方外露且可横向连通的显示器；同组共享轨道坐标，不跨无屏幕空间绘制。对不相连区域应通过明确策略分组，不能默默镜像。需通过真实设备评审后锁定边缘算法。DIP/物理像素映射由平台适配层处理；跨不同 DPI 可保持逻辑连续，但物理尺寸与跨边界视觉一致性需要真机校准，不能假定所有硬件完美对齐。若某 Linux Wayland 合成器不提供必要的跨屏定位能力，则明确降级为当前可支持的一块底部显示器，不能假称串联成功。

## 5. 复制来源 — V8 新增

### 5.1 UI

- Orbit：来源小图标 + 应用名置于卡片底部，类型/语言与时间置顶部；图库沿用内容优先布局。示例：微信、Chrome、Edge、VS Code、Figma、Finder、Notes。
- App 列表：独立紧凑来源列；窄窗口可仅展示图标，hover 显示完整来源。
- Inspector：标题附近显示来源和时间，不重复展示相同来源字段。
- Quick Look：底部状态区显示来源应用，不侵占文档/播放器内容空间。
- 搜索支持来源名称。偏好设置提供来源显示开关；该开关只控制展示，不代表停止采集。正式产品另设来源采集及隐私选项。

### 5.2 数据与捕获

建议 `source` 结构：`appId`（bundle ID、进程身份等）、`displayName`、`iconCacheKey`、`capturedAt`、`confidence`（verified/inferred/unknown）、可选 `windowTitle`、`url`（需用户许可，默认不额外采集）。

原生剪贴板变化事件不一定能可靠提供真正写入者。应区分已确认来源和根据前台应用推断的来源；异步写入、远程桌面、系统同步、延迟渲染、后台进程都可能导致误判。不能将前台应用猜测成已验证来源；未知时显示「来源未知」。来源图标优先从系统应用元数据获取，缓存和尺寸适配；不依赖网络在线拉取。

从微信复制的文本不代表掌握聊天对象或聊天内容上下文；从浏览器复制也不代表已取得网页 URL。URL/窗口标题只能在技术条件、用户许可均满足时记录。敏感应用排除、密码/一次性验证码保护、私密模式、删除来源元数据能力应由隐私层统一实现。HTML 中所有微信/浏览器等来源是演示元数据，不能监听真实应用。

## 6. Native Library — 管理窗口

保持 V6/V7 视觉基线：原生标题栏、侧栏、连续记录区域、Inspector；克制的控件、系统感圆角、适度玻璃和低饱和度高光。不得改为 Web Dashboard。

- 列表默认，图库可选，切换保留选择；时间分组、搜索、类型、固定、排序；预览栏可拉伸/隐藏，侧栏可收起，窗口可最大化/还原。
- 单击选择，双击复制；上下方向键导航，Ctrl/Cmd+F 搜索，Shift+点击范围选择，Ctrl/Cmd+点击离散多选，Ctrl/Cmd+A 当前结果全选；Delete 移除，Ctrl/Cmd+Z 撤销，Space Quick Look，Enter 复制。
- 多选后显示批量操作（固定/移除/预览），正式客户端须支持格式合理的批量复制；不同类型的复制语义需明确，不能简单拼接路径替代系统文件列表。
- 偏好设置承担低频功能：快捷键、外观、粒子、高光、动态效果、来源展示、隐私、存储/历史策略、清空与恢复演示（仅原型）。
- 编辑文本不应损坏非文本原始数据；正式版非文本记录采用只读预览与单独重命名/备注，保留原始文件内容。选择和滚动的更新不可让视图大幅跳动。

## 7. Universal Quick Look — 预览和集合

Quick Look 必须显示实际内容，而不是只有文件名/图标。按 MIME、文件头、扩展名以及文本特征注册独立 renderer，统一窗口框架、关闭与导航逻辑。预览只读，不修改源文件；代码、HTML、SVG、Office 宏等不执行，文件解析应限制资源消耗并隔离风险。

| 类型 | 正式客户端最低行为 | V13 原型状态 / 限制 |
|---|---|---|
| PDF | 真实页渲染、缩略图、滚动、翻页、缩放、页码 | 内置示例为页面图，本地文件交由浏览器 PDF 支持 |
| DOC/DOCX | 实际段落、标题、表格、分页、嵌入图片 | DOCX 基础结构化预览；非像素级、DOC 未实现 |

| JS/TS/Go/PHP/Python/JSON/CSS/Rust/SQL/Shell/YAML 等 | 精确语言检测、按语法分类着色、行号、选择复制、长代码滚动 | 基础词法高亮；不能替代 Tree-sitter 级语法解析 |

### 7.0 V10 专用渲染器与安全边界

**ZIP：** 卡片摘要展示少量内部文件名和条目数；完整预览左侧列出目录路径、大小、锁标识，右侧展示选中成员。加密成员不使用错误弹窗轰炸：显示内联密码输入，密码错误可重试，正确密码校验后显示真实内容。内置 `Private assets.zip` 是真实传统 ZipCrypto 加密 ZIP，演示密码 `lumen`；`Orbit assets.zip` 为真实普通 ZIP。原型读取中央目录，不写入磁盘；支持 Store/Deflate、传统 ZipCrypto、完整 CRC 校验。ZIP 文件限 64 MiB、展示前 2,000 个目录条目、成员解压限 1 MiB、文本显示限 12,000 字符。目录可读不代表文件已解密。AES 加密、加密中央目录、ZIP64、分卷、RAR/7z/TAR 等未提供实际解密/解析；正式产品应采用隔离的归档库，处理路径穿越、压缩炸弹、加密目录及异常文件名。输入密码不得持久化、记录日志或外传；关闭/切换应释放解密预览和缓存。普通目录树属于正式版需求。

**URL：** Orbit 卡片展示标题、域名与一段简要描述；Quick Look 地址栏支持复制、外部打开，主体直接渲染网页。内置 `Lumen — A space for ideas` 是实际本地 HTML 渲染示例，域名为保留示例域名，不是假装真实线上网站；Linear/Tauri/Material 的标题摘要为预置演示，非实时抓取。远程站点默认需用户点击加载以免剪贴板历史被动泄露；iframe 沙箱且无 referrer，某些网站会拒绝嵌入（CSP/X-Frame-Options），提供外部浏览器出口，不伪造网页快照或宣称加载成功。正式版在用户许可下实现隔离 WebView、真实元数据缓存、加载/重定向/失败/离线状态；禁止将应用权限、Cookie、剪贴板访问暴露给预览网页，拒绝危险协议及本地/私网自动探测。明确区分已缓存、实时、未知数据；不可任意绕过网站限制。

**代码：** JS/TS/Go/PHP/Python/JSON/CSS/Rust/SQL/Shell/YAML 示例；本地导入还接受 Java/C/C++/C#/Ruby/XML 等基础词法类型。支持行号、滚动、复制、换行切换；语言不是仅更换标题，词法分类、关键词、字符串/注释及代码配色随语言变化。HTML/SVG/Markdown 提供源代码和渲染模式，CSV 用带行号的表格，不执行 HTML 脚本、代码、宏。HTML 本地渲染隔离网络与脚本；Markdown 是基础受控子集。正式版以语法树和语言探测增强，支持大文件虚拟滚动、可访问性、主题适配、代码折叠、自动语言纠正；不运行剪贴板代码。

**小巧思：** 颜色显示大色样与一键复制 HEX/RGB/HSL；文本显示行数和字符数且保留换行；音乐集合采用封面叠层，播放队列独立；PDF 真实首页缩略图/页导航、Word 纸张层次、Excel 工作表和公式；图片、SVG 按图像比例显示，视频应优先实际帧缩略图，未知格式不伪装成已渲染。混合文件在同一 Quick Look 中切换独立渲染器。

### 7.1 批量复制的原子语义

一次从文件管理器复制 20 首歌曲，必须记录为一个 `ClipboardGroup`，Orbit 只占一张集合卡片（封面叠层、数量、来源、文件类型）。不能拆成 20 条独立剪贴板历史。再次复制一批文件则是另一条独立复制事件。集合保留文件顺序、原始文件标识、真实剪贴板 MIME/平台格式。

单击集合 = 粘贴整个文件集合；Space = 展开集合预览；移除集合 = 只删除剪贴板历史记录，不删除磁盘文件。App 中多选多个独立记录并预览，不应自动将它们合并成同一次历史事件。

| 集合组成 | 默认预览 |
|---|---|
| 全部音频 | 单一音乐播放器 + 队列；切歌、自动下一首、循环、封面、波形 |
| 全部图片 | 图片浏览器 + 胶卷/缩略图 |
| 全部视频 | 视频播放器 + 队列 |
| 多文档 | 文件列表 + 当前文件分页预览 |
| 多代码 | 文件导航 + 独立语言渲染 |
| 混合 | 通用文件列表 + 动态 renderer，不反复开关窗口 |

V12 有三首音频的集合和 App 多选；本地导入多文件会进入预览队列，而非写入真实系统剪贴板历史。正式客户端必须实现实际批量捕获与粘贴。

### 7.2 媒体行为

预览打开不默认发声，用户点击播放后才播放；切歌时连续播放，关闭窗口时暂停/停止并释放解码与波形任务。切换不同类型时停止旧媒体，避免多个播放器同时发声。媒体快捷键局部生效：Space 播放/暂停，左右键切换队列项（进度控件获取焦点时尊重控件操作）。无解码器/文件被移除时显示可理解的错误，不用假的播放进度或静态截图代替实际播放。封面优先读取真实元数据，缺失才生成占位；波形来自真实 PCM 数据或可靠缓存。

## 8. Motion & Material — 动画是核心需求

不是简单淡入淡出，也不是常亮霓虹。所有动效需服务于操作反馈、空间连续性和焦点识别。建议将下面的时间和曲线作为设计 token 起点，不是固定物理常量；真实高刷设备上调校。

| 触发 | 动画与状态反馈 | 建议时长 |
|---|---|---|
| Orbit 呼出 | 底边滑入、透明材质显现、卡片错峰入场（15ms 左右） | 400–520ms |
| Hover / 焦点 | 微浮起 6–10 DIP、相邻卡片轻微响应、指针高光、柔和边缘光 | 180–320ms |
| 光点 hover | 低亮休眠到激活、点自身缩放与亮度、临时浮动标签 | 180–360ms；离开后约 900ms 休眠 |
| 类型切换 | 五点视窗滑动、旧点缩小/新点放大、邻点沿方向错峰、旧轨道退出新轨道进入 | 滑动 460ms / 点缩放 290–385ms + 26ms 错峰 / 轨道 210–370ms |
| Orbit → App | 底部材质向上展开成窗口，目标内容裁切揭示、选中卡片向 Inspector 对接、其余区域错峰显现 | 590ms（原型） |
| App → Orbit | 管理窗口收拢、选中内容向原卡片归位、邻近卡片依序出现 | 520ms（原型） |
| 双向转场中再次切换 | 取消旧动画，使用当前材质与卡片几何作为新起点；清理旧图层 | 不锁定输入 |
| 横向滚动 | 连续位移、触控板惯性、可立即反向/中断 | 依据物理速度 |
| 粘贴 | 卡片短暂确认反馈、整个轨道向底边退场 | 200–320ms |
| 移除 | 内容逐段解构为粒子、跨屏连续补位（详见 §16） | 解构及尾粒熄灭约 760ms；之后才补位约 380ms（§17） |
| 撤销 | 原位展开、卡片淡入/弹性复位、焦点恢复 | 320–430ms |
| Quick Look 打开 | 从原卡片/记录坐标放大到窗口，背景柔化 | 400–480ms |
| Quick Look 关闭 | 向来源坐标收拢；不可见/已删除时中心退场 | 210–280ms |
| Quick Look 切换 | 内容连续过渡，窗口不闪白、不重建整个外壳 | 180–330ms |
| Library 列表/图库 | 共享元素/布局重排、保持选中记录与滚动上下文 | 220–330ms |
| 音乐播放 | 音频波形、播放状态、封面光感，暂停后停止活跃反馈 | 随播放状态 |

原型使用 CSS、Canvas、Web Animations API 和缓动曲线，V8 已接入从卡片或列表记录展开的 Quick Look 几何动画，V9 新增 Orbit 与 App 的双向几何桥接；这不等同于已实现 GPU 纹理级共享元素、全场景可中断弹簧或每屏同步渲染。正式版要求：

1. 统一单调时钟及动画状态机；动画途中允许新操作重新定向，禁止因等待动画而长时间锁住输入；删除等数据事务要保证正确性。
2. 变形优先使用合成层的 transform/opacity，避免每帧全量布局；虚拟化长轨道及列表，复用纹理与粒子缓冲区，异步生成缩略图。
3. 针对 60/120/144Hz 实际设备测试。帧预算分别约 16.7/8.3/6.9ms；这是性能目标，不是当前 HTML 的实测保证。跨屏使用统一时间基准，不要求不同物理刷新率强行锁相。
4. 动效关闭或系统 Reduce Motion 时去掉大幅移动、弹跳、粒子运动，保留必要的状态反馈。当前 HTML 支持减少动效，但原生仍应做全路径可访问性审计。
5. 高光、粒子、阴影、玻璃模糊的强度统一设计 token；保持浅色、深色可读性。隐藏状态停止持续渲染，空闲降低功耗。卡片类型差异主要通过内容呈现，避免彩虹色装饰泛滥。

## 9. 原生技术架构建议（非唯一技术选型）

```
Platform adapters (Windows / macOS / Linux X11 & Wayland)
  clipboard capture / source resolver / global hotkey / focus & paste
                       │
ClipboardStore ── EventBus ── History + Privacy + Cache
       │                       │
OrbitController           Native Library
  typeFilter / scrollOffset / selectedClipId
  DisplayTopology / shared animation timeline
       │
Per-display viewport windows ── Quick Look / Renderer Registry
                                  PDF / Office / Code / Image / Media
```

核心记录建议：`id`, `eventId`, `createdAt`, `kind`, `formats[]`, `source`, `contentRef`, `previewRef`, `fileItems[]`, `pinned`, `contentHash`。`ClipboardGroup` 作为一次事件的原子记录。二进制数据与元数据分开，缓存缩略图可重建，真实数据不可因缓存失效而丢失。文件路径记录需考虑原文件移动、删除和权限失效；明确快照与引用策略、磁盘配额、生命周期及用户控制。不要把文件路径文本当作文件剪贴板的等价替代。

系统级能力分别适配：Windows 的剪贴板格式/通知、原生窗口和焦点机制；macOS 的 pasteboard、窗口合成及辅助权限；Linux 区分 X11 与 Wayland（全局快捷键、剪贴板读取、置顶浮层、窗口定位、模拟输入可能受 compositor/portal 限制）。评估实际系统 API 与权限后决定技术栈；不要仅凭 HTML 成功就保证三平台功能完全一致。文档渲染可使用独立 PDF/Office 转换或渲染器，代码建议 Tree-sitter，音视频采用实际解码后端；引擎选型须评估许可证、沙箱、安全更新和格式覆盖。本文不强制 Electron、Tauri 或 Qt 等特定框架。

图标源：HTML 末尾 `Object.assign(paths,{...})` 为 V12 自绘 SVG 路径，开发可直接抽取为资产，不需要重新找图标。覆盖 copy/trash/close/remove/pin/edit/expand/restore/search/plus/left/right/zoomout/zoomin。复制用两层圆角矩形、删除用圆角桶身与盖、Orbit 用自绘交叉线 ×（V12 最末 `paths.remove` 覆盖）；禁止将关闭窗口与移除历史项混为一谈。正式版所有图标统一同一矢量体系；应用来源图标使用系统资产，不强行单色重绘。按钮保留可访问名称，危险操作、密码确认等必要文字例外。不可将 16px 图标尺寸等同于点击区域；无障碍或触摸模式应放大命中区（建议至少 44 DIP），不必同比放大图形。

### 13.2 信息密度与排版

采用系统 UI 字体：Windows Segoe UI / 微软雅黑 UI，macOS 系统字体 / 苹方，Linux 优先系统字体与 Noto CJK 回退；代码使用系统等宽字体。不要捆绑系统专有字体。标题仅表达内容身份；类型、语言、来源、时间、大小不重复。英文路径/URL 超长时省略但 tooltip/复制保留原文；代码不可把缩略内容当原文。避免全大写标签和过宽字距；相对时间、日期统一按系统 locale。浅色、深色、自定义系统文本缩放下逐项验收；不得用降低透明度代替全部层级设计。布局缩窄时优先隐藏非关键辅助元数据，保留可达操作，不让图标挤压文字或预览主体。

### 13.3 操作反馈的统一规则

Hover 160–200ms 背景与颜色，Press 约 .91 缩放、220ms 以内恢复；图标开关状态带颜色与形状/背景，不仅依赖颜色。复制成功：图标变对勾、轻弹确认、短暂「已复制」；真实失败则提示错误且不显示成功。Tooltip 显隐 140–180ms；危险色仅 hover/按下/失败语义，删除后仍按 §3.4/§8 完成粒子与补位。页面、模态、菜单、偏好设置、视图、预览内部切换都按 §8，避免动画堆叠、布局跳变和闪屏。任何操作都可通过键盘触达，焦点可见，快速反向不留下中间图层。

### 14.2 数据与状态接口（语义必做，命名可按技术栈调整）

```ts
type SourceConfidence = 'verified' | 'inferred' | 'unknown';
type ClipKind = 'text' | 'code' | 'link' | 'image' | 'color' | 'document' | 'audio' | 'video' | 'archive' | 'group' | 'other';
interface ClipRecord {
  id: string; eventId: string; createdAt: number; kind: ClipKind;
  formats: { mime: string; nativeType?: string; blobRef: string }[];
  source: { appId?: string; name?: string; iconKey?: string; confidence: SourceConfidence };
  files?: { id: string; name: string; mime?: string; size?: number; ref: string }[];
  pinned: boolean; contentHash?: string; previewRef?: string;
}
interface OrbitState {
  visible: boolean; filter: string; selectedClipId?: string;
  scrollOffset: number; perFilterOffsets: Record<string, number>;
  topologyRevision: number; animationEpoch: number;
}
interface PlatformCapabilities {
  capture: boolean; globalHotkey: boolean; autoPaste: boolean;
  positionedOverlay: boolean; multiDisplayContinuous: boolean;
  nativeBlur: boolean; reason?: string;
}
```

Core 为唯一真值；UI 不直接持有重复历史。事件建议 `ClipboardCaptured`、`ClipRemoved`、`ClipRestored`、`SourceResolved`、`TopologyChanged`、`OrbitVisibilityChanged`、`FilterChanged`、`SelectionChanged`、`PasteRequested`、`PasteResult`、`PreviewOpened`、`PreviewClosed`。每个事件使用唯一记录 ID / 事务 ID；异步任务使用 epoch/取消信号，旧结果不可覆盖新选择。应用自身写剪贴板时使用事务标记或可验证的格式/内容指纹与短时抑制，避免递归捕获；不能吞掉用户真实的后续复制。

粘贴事务：捕获目标应用及焦点 → 选择记录 → 验证原始格式/文件可用性 → 写系统剪贴板 → 收起浮层并恢复目标焦点 → 在权限允许时发出一次粘贴 → 根据可观测结果显示真实状态。系统通常无法验证目标应用已经消费内容，不能把发出输入事件等同于对方粘贴成功。失败提供清晰降级，避免重复粘贴。删除事务只修改历史和缓存引用计数；undo 恢复原序列和元数据；绝不删除磁盘原文件或擅自清空系统剪贴板。预览是只读，解析任务、网络、解码器在关闭时取消。

多屏例：三块同排逻辑宽分别 1920、2560、1440，轨道视口区间分别 [0,1920)、[1920,4480)、[4480,5920)。卡片全局 x = 起始边距 + index×(cardWidth+gap) − scrollOffset；每个窗口只渲染与其区间相交部分，用本地变换裁切；光点与起始边距只计一次。2×2 布局只选择下排，混合 DPI 将各平台几何归一到逻辑坐标；非共线、不相连的底边不得假造中间屏幕。建议默认选包含最下方外露边缘且横向连通的底部组；若多个不相连组，优先含当前活动屏的候选组，否则选跨度最大组，仍不复制轨道。具体规则需经非规则拓扑设备评审确认。窗口热插拔重算 viewport 与滚动上界，不重建数据或重置 ID。

### 14.3 性能、错误与安全门槛

- 生产库需虚拟化 10,000+ 条记录、预览任务异步且可取消；目标输入响应 p95 < 100ms、缓存已热呼出首帧 p95 < 100ms（选定基准设备测量）；动画预算 60/120/144Hz 约 16.7/8.3/6.9ms。冷启动单独测，不将原型数据量视为生产性能证明。
- 动画引擎对隐藏窗口停帧、对媒体关闭释放资源；连续反向或滚动不能积压动画；系统 Reduce Motion 优先于产品特效开关。
- 存储本地默认、容量与保留策略可配置；用户排除敏感应用，不默认上传历史、URL 或来源；日志不记录原文、密码、文件路径等敏感内容。预览网页和文档解析隔离，不执行脚本、宏、代码或压缩包内容。
- 错误 UI 统一：格式不支持、权限不足、文件不存在、密码错误、网页被阻止、播放失败、存储失败，各自显示准确可恢复操作，不以空白或假内容掩盖。删除/撤销、加密缓存、临时文件和导入生命周期应有专项测试。

## 16. V12 专项实施合同：Optical Capture / Release 与原生系统适配（P0）

### 16.1 设计意图与边界

本版粒子灵感来自产品方描述的 HarmonyOS 清理与碰一碰接收动效：内容解构、光能转移、内容聚合。不是要求复刻华为素材、商标、系统实现或逐帧动画；本原型独立设计。Kinetic Dots 仍只允许光点自身尺寸与亮度变化，严禁将下述卡片粒子扩散套到光点导航。

Orbit 继续保持屏幕底边纯卡片形态。新增事件没有常驻按钮、筛选栏、弹窗或标题条；HTML 顶部的「模拟复制」和系统选择器是测试台，**正式产品中不得出现**。原生捕获由系统 ClipboardCaptured 事件驱动，不要求用户再执行一步。新旧平台皮肤共享同一 Store、类型筛选、预览和动作，不复制一套业务实现。

### 16.3 Optical Release（OR-01）：删除不是卡片整体下沉

使用内容纹理驱动的局部解构：原卡片的轮廓、内容与高光沿斜向前沿逐段消失，解构处产生不同尺寸、透明度、速度的粒子；粒子沿风场轻微弯曲并向外上方离开，少量星芒在高亮处短促闪动。不是在整张卡片淡出之后才播放独立烟花，也不是每次随机爆炸覆盖全屏。

| 时间 | 内容与粒子 | 轨道 / 数据 |
|---|---|---|
| 0–80ms | 按压回弹、捕获当前卡片可见纹理 | Store 原子提交删除；保留 ID、原序、元数据供撤销 |
| 80–350ms | 斜向解构前沿，纹理变成局部光粒，亮度由卡片原有色调决定 | 保留原卡片的布局槽，相邻卡片保持原位置；禁止提前挤入 |
| 350–760ms | 尾部粒子逐渐变小、自然熄灭；删除卡片完全消失 | 原槽仍保留；逻辑焦点已定位下一可用项；Orbit 不退场 |
| 760–1140ms | 粒子层已清理，不再生成粒子 | 原槽宽度和间距连续收缩，相邻卡片同步平滑补位 |
| 完成 | 清理临时纹理、画布/合成节点 | 不删除任何磁盘原文件；单次删除只产生一次撤销记录 |

HTML 使用 Canvas 粒子 + DOM 卡片副本 + 动态渐变遮罩，采样卡片区域和类型色板（非逐像素真实纹理采样）。正式版应在 GPU 合成层采样真实 RGBA 纹理，亮度和 alpha 参与粒子生成；同一纹理可复用于捕获、删除与撤销。建议粒子池按 DPI/面积和负载自适应；V13 示例使用按卡片面积分布的细粒子网格与缓存光斑精灵，原生数量不限于此，遵循帧预算与视觉清晰度。

### 16.4 Optical Capture（OC-01）：Orbit 激活期间实时收到新复制

原则：**事件立即入库，动画异步表达数据变化；不得用动画作为写入门槛。**

1. 外部应用产生剪贴板事件，平台适配器读取实际格式及来源，Core 去重（应用自身写入/重复通知按事务识别，不误吞不同的新事件），提交唯一 ClipboardCaptured。原子批量复制仍为一个集合。
2. 当前类型匹配、轨道在头部且新位置可见：在最新位置先建立布局槽，旧卡片连续右移，光粒从外围逐步向卡片轮廓和内容收束，斜向显影成形，最后清理临时层。原有选中 ID 不变；仅空列表首次捕获选择新记录。不要自动触发粘贴。
3. 用户已横向滚动到旧记录：保持其视口锚点及选中 ID，更新全局序列，不强制滚回头部；新记录在视口外就不播放屏幕外粒子。允许低干扰的待查看提示或光点计数（不弹窗），按 Home 回到头部。
4. 当前筛选不匹配：只更新全局记录及对应类型计数；如目标点在可见五点内可短暂尺寸反馈，绝不切换用户当前类型。空类型匹配时自然从空状态变为第一卡片。
5. Quick Look 正打开、App 为前台、Orbit 隐藏：保存数据；不在屏幕上擅自呼出 Orbit，不遮住预览，不抢焦点。App 正在搜索/多选时更新结果并保留上下文，后续关闭预览时显示最新数据。
6. 连续复制、撤销、立即删除新记录、换类型、跨屏切换、关闭 Orbit：事务独立于动画，依据 ID 和 revision 清理旧临时层；不允许幽灵卡片、重复记录、计数漂移或遮挡当前窗口。可重定向合成层，而非排队播放 N 次长动画；高负载优先缩短动效、合并视觉反馈，不能丢数据。

捕获时间参考：0–80ms 创建槽和保存；0–460ms 布局连续移动；0–760ms 粒子收束与纹理逐步成形；达到稳定状态立即释放缓存临时引用。撤销使用同一聚合语言在原逻辑位置恢复，不等同于重新复制、不能把旧记录移到最新位置。原生保持真实纹理、速度继承和统一动画时间线。关闭动效时保留状态/数据、直接完成布局；关闭粒子时使用短位移/透明度转换，不生成 Canvas 粒子。隐私排除的事件不入库、不播放内容粒子。

## 17. V13 实施合同：Fluid Choreography（全部 P0）

本节是开发人员的最终裁决依据。V12 删除动画在开始时释放了布局，左右面板折叠直接隐藏造成跳变；V13 禁止这种实现。产品动效追求连续、灵动、响应及时，不能用一段淡入淡出掩盖瞬间重排。HTML 是实际可交互参考，顶部系统/屏幕模拟及「模拟复制」仅用于测试；不要出现在产品 UI 中。

### 17.1 Orbit：时间让位，而不是隐藏

- 默认：顶部类型在左、相对时间在右，× 不可见；时间始终可读，不以透明度隐藏。使用等宽数字，禁止用颜色或位置变化导致文字截断。
- Hover / 键盘聚焦：时间与类型间距连续调整，时间向左约 29 DIP，类型文本在极窄宽度时优先省略；时间不得与类型或 × 重叠。时间区域先让位，再显示 ×。原型右内边距由 12→41 DIP；约 220ms；× 约 150ms 后开始显现，透明度过渡约 120ms。
- Hover 离开：× 先退出，时间延迟约 100ms 后平滑回到原位。直接扫过多个卡片应重定向现有动画，不突然闪烁或跳位。时间保持真实相对时间（例如「1 分钟前」），不需要重复标注来源/时间。
- × 使用已有自绘圆端交叉线与玻璃命中区域，V13 视觉外框 26×26 DIP，图形约 16 DIP；触控/无障碍可扩大命中区并有等价右键入口。危险色、旋转、按压反馈继承 §16.2；不引入常驻红色。
- 低动效：立即完成让位与显隐，仍然不能覆盖时间。各平台字体、文字放大、DPI 和多屏裁切均须测试。

### 17.2 删除：粒子解构与空间释放严格分离

**数据事务与视觉占位分离。** 用户触发删除即提交 ClipRemoved，保留撤销记录；立即从可操作历史、编号、键盘导航和计数移除。视觉上以不可交互、无可访问焦点的 reservation 占据原卡片宽度与间距。不是将原记录留在数据库中等动画结束。

| 阶段 | 参考时序 | 可观察行为 |
|---|---:|---|
| Commit / Reserve | 0ms | 数据删除一次、锁定原占位、截取卡片纹理/视觉副本；其余卡片坐标保持 |
| Dissolve | 0–390ms | 斜向渐进解构，粒子从正在消失的区域产生；不是整卡透明后播放烟花 |
| Drift / Extinguish | 约 390–760ms | 粒子沿轻微弯曲风场漂移、衰减、熄灭；占位宽度不变 |
| Release Space | 粒子完成后约 380ms | 卡片槽宽度与末端间距连续趋近于 0，后续卡片同一坐标系平滑补位；不跳变 |
| Settle | 约 1140ms | 删除占位、纹理、粒子任务，状态稳定；不留下空隙、遮挡或幽灵卡片 |

此时长是视觉基准而非强制每次等待 1140ms。关键是阶段依赖：`particlesFinished` → `startReflow`；不能以固定计时猜测 GPU 已经完成，也不能让尾粒尚在原位置时相邻卡片挤入。正式原生 compositor 使用真实纹理颜色及 alpha，亮点具有局部来源；建议用粒子池、缓存光斑、批量绘制或 GPU instancing 控制帧预算。V13 HTML 的 `v13Release` 使用 DOM 遮罩、内容类型色板、密集分层粒子与缓存光斑，并非 GPU 逐像素纹理采样。

**并发/边界：** 多次删除应分别维护各自 reservation，不全局阻塞复制/键盘/滚轮；新复制仍立即入库，若新项出现在首位则正常聚合，既有删除 reservation 作为轨道一部分移动，粒子随锚点更新。撤销发生在解构或补位中：撤销删除事务、终止对应粒子任务、复用原槽，按当前宽度恢复；已完成删除则按原逻辑位置聚合。切类别、关闭、进入 App、显示器拓扑改变、窗口隐藏、减少动效设置变化须清理临时层并按当前 Store 重建，不播放旧屏幕残影。原生应将视口锚点与统一动画时间线传给所有底部屏幕；不同 DPI/刷新率不得出现跨屏补位断层。

关闭粒子但保留动效：短解构/淡出约 180ms，完成后约 380ms 连续补位。减少动态效果或关闭动效：直接完成数据和布局变更，不等待任何装饰动画。每个被删除项都可以撤销，原文件不受影响。

### 17.3 Native Library：左右面板连续折叠

- 左栏开关在原生标题工具区；右 Inspector 开关在工具栏。点击后当前宽度连续改变至目标值；列表/图库占用实时释放的空间。切换期间不使用 `display:none` 立即删除布局轨道，不截屏拉伸整个窗口的文字。原型使用同构 CSS Grid track `side | content` 及 `history | splitter | inspector`，约 380ms、`cubic-bezier(.28,.58,.26,1)`；正式版可改为可中断弹簧。
- 关闭时面板内部保持原排版，随可见区域裁切、少量向外偏移和渐隐，避免文字挤压成一列；打开时相反。过渡过程中，列表内容继续以真实字体大小重排。图库换列时用 keyed FLIP / 位置弹簧，避免卡片跳层。保留当前记录、搜索词、选中状态、滚动上下文及用户调整过的 Inspector 宽度。
- 动画期间再点击应从当前呈现宽度反向，不从初始端点重新开始。可同时操作两侧，不锁界面。拖动 splitter 时宽度直接跟随指针（禁用缓动延迟），松手后恢复面板动画能力；键盘调宽也可轻微过渡。
- 隐藏面板退出 tab/focus 顺序并设置 accessibility collapsed，开关提供 expanded 状态；恢复后可再次访问。若焦点原在折叠区域，回到触发按钮或可用内容区。低动效时立即布局变化，不保留不可见焦点。
- **删除底部全局状态栏以及侧边栏底部的「本地资料库 / xxx 条记录 · 原型」区块。** 不在最终客户端复刻任何原型状态说明或快捷键底栏；不预留其高度，不换名恢复。偏好设置入口仍保留在侧栏底部。必要记录数量只在上下文标题/分类中出现，批量选中信息保留在批量操作区域。Quick Look 自己必要的媒体、文档和来源状态不属于本条删除范围。

## 18. V14 — Semantic Precision（继承；§19 优先）

本节是实施合同，不是可选视觉建议。覆盖前文中使用通用 file/code 图标、硬亮星芒、V13 粒子时间参数、字号及重复元信息的旧规则。前文的全部产品需求、跨平台、连续多屏、实际预览、动画及原生验收仍有效。HTML 的最新实现位于 `V14 / Semantic identity` 段及新增 CSS；粒子时序在 V13 的 release 和 V12 的 capture 函数中直接修订。不要复制旧的 `ic(c.type)` 作为最终类型图标。

### 18.1 视觉与类型识别的单一事实源

建立 `ContentIdentityRegistry`，而不是让列表、卡片和预览各自 switch。语义类型、语言识别和 renderer availability 必须分离：一个 RAR 文件即使尚未安装解码器，也应显示压缩包图标，而不是未知文件；不可反过来因为有图标就显示假预览。

```ts
interface ContentIdentity {
  family: 'text' | 'code' | 'image' | 'color' | 'link' | 'document' | 'audio' | 'video' | 'archive' | 'collection' | 'file';
  subtype: string;               // e.g. pdf, docx, mp3, zip, folder
  language?: string;             // stable id: js, ts, go, php, py, rs, sql, sh ...
  confidence: 'confirmed' | 'probable' | 'unknown';
  glyphId: string;               // semantic identity, shared across all views
  displayName: string;           // localized, not a hard-coded filename
  rendererId?: string;
  previewAvailability: 'ready' | 'loading' | 'unsupported' | 'missing' | 'locked' | 'error';
}
```

识别优先级：用户确认的类型/语言 > 已验证的 MIME/文件头及可靠扩展名（冲突时优先文件头） > 文件名特殊规则（Dockerfile、Makefile 等） > 内容特征、词法/语法分析 > 未知。文本剪贴板可能是源代码，需分析其结构；普通聊天文字不能仅因出现 `return`、`go`、`select` 就变成代码。歧义时不猜测，允许用户纠正；纠正后同步刷新所有视图及搜索索引。HTML 目前用明确 lang、扩展名及有限的高置信结构启发式识别，正式版必须引入语言识别/语法解析，并建立置信度及覆盖率测试。不得执行代码来判断语言。

### 18.4 Soft Dissolution — 棉柔光学粒子

删除保留 V13 的两阶段时序，但粒子不再是尖锐星芒或硬亮圆点。使用预乘透明度软光斑、宽羽化掩模、细微速度分布与缓慢曲线漂移。渐进解构的局部纹理与粒子色应来自原卡片 GPU 纹理，浏览器目前为配色近似。真实物理表现：颗粒像细软光尘从卡片内部缓慢脱离，边缘是柔和的梯度，亮度先升后降，不闪爆、不突然截断；相邻粒子大小、速度、生命周期轻微不同，不是方形网格或烟花。

| 动效 token | V14 基准 |
|---|---|
| dissolve.hold | 920 ms；尾粒必须完全熄灭后才释放空间 |
| dissolve.front | 约 480 ms 推进，宽羽化带；移除硬切线 |
| dissolve.particle.life | 320–500 ms，局部错峰 |
| dissolve.particle.drift | 更短的位移及缓入缓出，轻微弯曲 |
| dissolve.particle.alpha | 正弦包络、峰值约 0.58；禁止硬亮十字星 |
| dissolve.reflow | 420 ms，连续收缩原槽宽度和间距 |
| capture / restore | 约 900 ms，软光颗粒反向聚合，保留焦点 |
| reduce motion | 无粒子、短反馈或立即切换，操作结果等价 |

时长是调校基准，不是机械等待：生产应根据粒子尾部实际完成事件触发释放；支持撤销、滚动、窗口关闭、跨屏、同时捕获、切类别，不阻塞数据事务。保持 V13 的非交互占位直到解构完成。性能预算与高刷验收沿用 §8/§17；不要用更大的亮度或更多粒子掩盖卡顿。使用透明纹理和受控粒子预算，禁止每帧无界创建 DOM 节点。

### 19.2 原生 1:1 还原合同：统一体验，不统一系统外壳

1:1 是发布验收约束，不是宣称不同系统字体栅格化、窗口合成与操作系统行为的物理像素完全一样。**产品内容区必须对标 HTML，系统拥有的区域必须对标该系统。** 禁止把 AppKit 交通灯绘制到 Windows，禁止将 Windows 标题栏放到 GNOME，禁止同一应用内部混用三种风格的菜单、滚动条与对话框。

|---|---|---|
| 品牌与内容 | 卡片比例、排版层级、图标语义、状态、内容预览、空间运动 | 系统字体、文本缩放、高对比度、语言、输入法 |
| 窗口 | 三栏相对比例、Inspector、工具栏位置、无冗余底栏 | 原生窗口按钮、标题栏命中、窗口拖动、最大化、全屏、系统菜单 |
| 材质 | 光学玻璃视觉层级、清晰内容、阴影及高光、明暗主题 | 系统透明度/减少透明、合成器、色彩配置；不支持则用一致的静态材质 |
| 动效 | 完整呼出/退场、聚合/解构时序、面板折叠、共享元素、键盘反馈 | OS 已提供的窗口动画不得叠加一套冲突动画；尊重减少动态效果 |
| 操作 | 撤销、真实粘贴、全路径快捷键及焦点回归 | Command/Option 或 Ctrl/Alt、系统权限、原生拖放、辅助功能树 |

**Windows：** 对照 V15 的 Windows 预览验证内容区；窗口控制使用系统标准语义、命中测试及 DPI 感知。Snap、拖动最大化/还原、任务栏、Alt+Tab、系统菜单、焦点、IME、多屏工作区及高对比度均应实机验证。标题栏和客户区交界不能出现双重边框、两套阴影或不同背景色的割裂。系统配置控制窗口行为，不能让自绘按钮破坏正常窗口管理。Windows 10/11 是否都列为支持版本由 M0 决定，不声称旧系统具有新系统材质能力。

**macOS：** 对照 macOS 预览；交通灯及其悬停、全屏/退出全屏、最小化、Dock、Spaces、系统菜单和应用激活必须采用真实系统语义。原生弹窗、菜单、滚动和快捷键使用系统习惯，窗口内容视觉连续。不可用仿交通灯 HTML 控件代替真实窗口管理。

**Linux：** GNOME 和 KDE Plasma 分别验收，支持的 X11/Wayland 会话组合逐项列明。必须遵循用户配置的窗口按钮位置、桌面主题和字体、系统缩放、窗口管理器、工作区和合成能力；服务器端装饰存在时不能再叠加自绘标题栏。合成器对全局快捷键、剪贴板捕获、顶层浮层、跨屏定位、跨应用粘贴可能有不同权限和支持程度，M0 必须按实际桌面环境验证，不得通过不安全的权限绕过实现。能力不具备时明确选择受支持的模式及用户可理解的降级，不在所有系统牺牲原设计，也不宣传未验证功能。对于不支持真正跨屏轨道的组合，单屏降级必须得到产品确认；禁止用镜像冒充连续轨道。

### 19.3 设计资产的提取与工程管理

- 设计交付不要求特定框架。提取 HTML 中最终生效的 CSS token、SVG `paths`、V14 类型注册表和原型各状态截图；由共享的 design-token 资源和 `ContentIdentityRegistry` 提供给三端。旧样式因历史覆盖存在，不得取第一条 CSS 当最终值。图标按最终 SVG 矢量渲染，不截图栅格化；系统来源应用图标来自 OS，无法获取才用中性回退。
- 每个组件提供明确 Normal / Hover / Pressed / Focused / Selected / Disabled / Loading / Error / Empty / Exiting 状态（只为语义适用者实现）；不同内容类型共享框架但保留专用渲染器。所有文本、标点、单位、语言图标、时间及元信息按 §18；不添加未经批准的标题、分隔线、说明、原型底栏或 Web 控件。
- 若采用共享 GPU 渲染与原生宿主，需保证应用控件辅助功能树、键盘、IME、缩放、菜单和窗口行为完整。HTML 不可直接作为普通网页壳发版；技术实现必须证明原生交互与动画质量。各平台允许不同实现，但同一语义测试向量必须通过。

### 19.4 1:1 截图与动画验收方法

所有验收截图由开发在 **同一 V15 初始数据、同一逻辑窗口尺寸、同一主题及平台预览** 下重新生成，不依赖旧版本截图。实验顶栏与模拟桌面不属于正式 UI，不计入截图比较。将原型与实机按内容区边界对齐，记录实际系统字体、缩放、窗口装饰和颜色配置。

| 项目 | 建议验收门槛（非已测原生结果） |
|---|---|
| 静态几何 | 100% 逻辑缩放时关键内容锚点、控件尺寸、间距、圆角和文字基线的偏差不超过 1 DIP；系统字体换行/原生装饰的合理差异单独批准 |
| 颜色 | 纯色 token 直接复用；同一受控背景、色彩空间下对比半透明材质，不能以完全不同的颜色/阴影替代 |
| 图标 | 100%/125%/150%/200% 以及 Retina 缩放逐项目视；所有类型语义正确；不得用通用文件页替换已知类型 |
| 可访问性 | 键盘遍历完整、焦点可见；普通辅助文字对比度目标至少 4.5:1，必要非文字控件至少 3:1；高对比度和放大文本允许无损重排 |
| 动画 | 对每条关键路径保存正常速度与逐帧慢放录屏，标出触发、主要过渡、完成、反向中断；参考 token 时长，目标误差约 ±10%，物理动画可因初始速度变化而偏离；必须保持语义及先后顺序 |
| 帧性能 | 60Hz/120Hz/144Hz 的单帧预算约 16.67/8.33/6.94ms；实机测量 P95 帧耗时、掉帧、输入延迟和显存/内存，约定硬件矩阵后验收。不能将浏览器测试视为原生高刷测试 |
| 多屏 | 不同缩放、刷新率、横向/纵向排列、热插拔及睡眠唤醒；显示区域对应全局逻辑轨道；焦点、动画时钟和数据全局唯一；不得跨屏复制同一列表 |

每个发布候选版本要提供原型/实机并排截图、差异清单、录屏、平台/版本与硬件、测试结果。差异处理：设计缺陷修复；原生系统约束登记并由产品签字；未通过 P0 禁止发版。不存在“差不多就可以”的视觉验收。截图像素差异工具仅用于发现偏差，不能因为字体抗锯齿或系统合成差异自动判定不合格，也不能因为截图一致就跳过真实交互测试。

# Web Terminal 会话总览验收 — 2026-11-15

正式入口为 `http://127.0.0.1:9527/ui/terminals`，侧栏“会话总览”。页面复用现有 Web Terminal，显示一个可交互主窗口和其他会话的实时预览。点击预览切换控制，支持搜索、按类型筛选、隐藏/恢复和刷新发现。关闭原生会话的网页视图只分离网页客户端，原后台任务继续运行。

数据库单库切换和标准 CLI/服务构件兼容修复已在 [单库迁移记录](2026-11-15-single-business-database-cutover.md) 记载。本次终端收口没有再次迁移数据库或改表名。

## 本轮缺陷与修复

- 持续输出造成订阅溢出后，旧连接只剩心跳，浏览器无法察觉失流。服务现在关闭异常终止的传输，让浏览器恢复连接；普通 PTY 也能按原 termId 重绑。
- 早到输出原先按帧数丢弃，突发输出可能缺行。接入阶段改为容量控制和读取背压，xterm 接管后释放缓存压力。
- 单个旧客户端输入返回 404 时，前端曾恢复整个总览，多个回调造成重复接入。恢复现在限定实例并按连接代次合并，过期响应不能替换新连接。
- 用户输入与终端能力回复混在同一缓冲区时，旧回复会随用户文本重发。队列现在逐片段标记来源；确定未写入的用户片段保序恢复，旧客户端协议回复丢弃，结果不明的网络写入不自动重复发送。
- 历史 tmux 回放漏过滤 DECRQM 查询，导致 `?2026;2$y` 等回复进入原任务输入框。持久会话回放现在过滤该查询，实时协议协商仍可继续。

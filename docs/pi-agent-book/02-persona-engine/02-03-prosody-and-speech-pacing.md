## 1. 核心专业术语

| 术语 | 中文释义 | 说明 |
| :--- | :--- | :--- |
| **Micro-pause Insertion** | **微停顿注入** | 在从句连接词与转折词处插入 40~120ms 呼吸停顿标记。 |
| **Filler Word Injection** | **语气助词注入** | 在思考复杂问题时自然吐出“嗯...让我看看”，掩盖后台检索的 TTFT 延迟。 |

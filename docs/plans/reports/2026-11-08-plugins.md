# plugins-A：插件面迁 Go（只读切片）

日期：2026-11-08
分支：`slice/plugins-wt`（基线 main @ 65555ab7）
结论：**列表与投影一致性诊断已迁到 Go 只读接口；启停/安装/卸载/诊断仍以 Node 为唯一写入口。**

## 1. 真实数据源与契约盘点

| 能力 | Node 实现 | 持久事实 | 运行时耦合 | 本次 Go 处理 |
| --- | --- | --- | --- | --- |
| 插件列表 | `lib/plugins/control/control.js` `list()` | `app-state.db` → `app_kv` → key `plugins.control.v1` | 无（仅读状态） | **已迁，只读** |
| 启用 / 停用 | `control.enable()` / `control.disable()` | 同上，`revision` CAS | `runtime.publish()`：宿主 prepare → 以 expectedRevision CAS 提交 → activate | **未迁**，写入口必须留在 Node |
| 安装 / 卸载 | `control.install()` / `uninstall()` | 同上 + `$AIH_HOME/plugins/accepted`、`extracted` 文件 | 校验清单、签名、摘录制品 | 未迁 |
| 诊断 | `control.doctor()` | 同上 + 制品文件存在性 + 运行时状态 | 读 `runtime.status()`、pricing | 未迁 |
| 投影推送 | `lib/plugins/control/runtime-service.js` `liveProjections()` → `go-projection-sync.js` | 不落库（内存代次快照） | `PUT /v1/management/plugins/projection` | 已有；本次把它与列表并排输出 |
| WebUI | `web/src/components/toolkit/AihPluginPanel.tsx` → `web/src/services/api.ts:2527` | — | Node `/v0/plugins`、`/v0/plugins/doctor` | 契约字段兼容，可直接改接 Go |

关键契约：

```jsonc
// app_kv['plugins.control.v1']
{
  "schemaVersion": 1,
  "revision": 4,                     // 每次控制面写入 +1，Node 用它做 CAS
  "installed": [{
    "pluginId": "echo", "version": "1.0.0", "digest": "sha256:…",
    "manifest": { "contributes": [{ "id": "echo.reply", "capability": "gateway.request", "order": 0, "failurePolicy": "deny" }] },
    "signature": { "status": "unsigned" }, "permissions": null
  }],
  "instances": [{
    "instanceId": "echo", "pluginId": "echo", "version": "1.0.0",
    "enabled": true, "configuration": { "token": "…" }
  }]
}
```

- 列表契约与 Node `control.list()` 对齐：`revision`、`installed[]`（不回显 `manifest` 全文，只给 `contributes` 的 id）、`instances[]`（配置只给键名）。
- 鉴权：Node 的 `/v0/plugins` 只认管理密钥（未配置返回 503）；Go 侧沿用管理面 `Authorizer`，未授权返回 401。
- 写路径不可旁路：Node 的 `enable` 必须先让宿主准备候选代次，再用 `expectedRevision` 做 CAS，最后激活。Go 直接改 `app_kv` 会造成「状态已启用、宿主没有代次」的分叉，因此本切片不做写。

## 2. 新增 Go 接口

```http
GET /v1/management/plugins
Authorization: Bearer <management key>
```

响应在 Node 列表字段外追加只读标记、来源与投影一致性：

```jsonc
{
  "ok": true,
  "readOnly": true,
  "source": "node-app-state",
  "revision": 4,
  "installed": [ … ],                 // 与 Node control.list() 同字段
  "instances": [ … ],                 // 与 Node control.list() 同字段
  "runtime": {
    "activeGeneration": 9,            // 存活代次的最大值，0 表示没有
    "generations": [8, 9],
    "retiringGenerations": [8],
    "contributions": [ { "id": "echo.reply", "capability": "gateway.request", "instanceId": "echo", "generation": 9, … } ],
    "instances": [ { "instanceId": "echo", "status": "projected", "generations": [9], "contributions": 1 } ]
  },
  "consistency": {
    "ok": false,
    "issues": [ { "code": "plugin_instance_not_projected", "instanceId": "x", "detail": "活跃代次缺少贡献项：…" } ]
  }
}
```

`runtime.instances[].status`：`projected`（活跃代次有贡献项）、`retiring`（只在旧代次）、`absent`（没有投影）。

一致性问题码：`plugin_installed_invalid`、`plugin_installed_duplicate`、`plugin_instance_duplicate`、`plugin_instance_artifact_missing`、`plugin_instance_not_projected`、`plugin_instance_contribution_mismatch`、`plugin_projection_orphan`。这些只报告，不自动修复。

## 3. 只读 / 可写边界

| 操作 | Go | Node |
| --- | --- | --- |
| 读列表 / 读投影 | ✅ `GET /v1/management/plugins` | ✅ `GET /v0/plugins` |
| 投影推送 | ✅ 已有 `PUT /v1/management/plugins/projection`（只收 Node 推送） | ✅ 推送方 |
| 启用 / 停用 | ❌ 405 `plugin_control_read_only`（`Allow: GET`） | ✅ 唯一 owner，带 revision CAS |
| 安装 / 卸载 / doctor / pricing / accounts | ❌ 未迁 | ✅ 唯一 owner |
| 建库 / 建表 / 写 app_kv | ❌ 从不 | ✅ |

只读的技术保证：

- 数据库以 `mode=ro` 打开，并额外设置 `_pragma=query_only(1)`；缺少文件时直接返回空状态，不创建 `app-state.db`。
- 只有在**确认没有 `-wal` 文件**时才允许 `immutable=1` 重试；有 WAL 时坚持普通只读连接，读不到就返回 503，绝不返回过期快照。
- 单次 `SELECT` 取整份 JSON；不会读到写了一半的记录。

## 6. 还需要什么接线（Node 侧未改，给出位置）

1. **Node 管理路由** `lib/server/plugin-management-routes.js`：
   - `handlePluginManagementRequest` 里 `GET` + `pathname === '/v0/plugins'` 时，把请求转发到 Go 的 `GET /v1/management/plugins`（带同一个管理密钥），返回体可直接透传；`revision/installed/instances` 字段与现有 WebUI 兼容。
   - `POST /v0/plugins/enable|disable|uninstall`、`GET /v0/plugins/doctor` 继续留在 Node，不能转发到 Go（Go 是 405）。
2. **WebUI** `web/src/services/api.ts:2527`：继续走 Node `/plugins` 即可，无需改解析；若要直连 Go，把 base 指到 `/v1/management/plugins`（字段是超集，多出的 `readOnly/source/runtime/consistency` 可忽略）。
3. **启动参数**：Go core 必须拿到与 Node 相同的 `AIH_HOME_DIR`，否则 `NewReader` 失败，该路由不挂载（404），投影与推理闸门不受影响。
4. **路由清单**：`contracts/route-ownership/manifest.json` 若要把 `/v1/management/plugins` 登记为 Go 数据面路径，需要单独补条目；本切片不改 Node 侧序列化。
5. **权限**：管理面复用现有 `managementAuthorizer`，与 `/v1/management/plugins/projection` 同一把管理密钥。

## 8. 剩余缺口

- **启停/安装/卸载/doctor 未迁**：写路径需要 Go 接管 Plugin Host 生命周期，或 Node 暴露内部 RPC 让 Go 触发发布；当前数据事实在 Node，Go 写 `app_kv` 会造成状态与宿主代次分叉，故不做。
- **revision CAS 仍归 Node**：Go 读取的是某一瞬间的整份文档；若 Node 在读取后立刻提交新 revision，调用方看到的是上一版（不会看到半条记录）。
- **瞬时不一致**：Node 的 `enable` 是「CAS 提交 → activate」，两次读之间可能短暂出现 `plugin_instance_not_projected`；这是观测窗口，不是故障，诊断时应结合 `runtime.retiringGenerations` 判断。
- **活跃代次定义**：取存活代次的最大值。Node 排空中的旧代次只标 `retiring`，不参与 `not_projected` 之外的判断。
- **WAL 只读前提**：Node 运行时依赖 `-shm`；没有 `-wal` 时才允许 `immutable` 回退。Node 异常退出导致只读连接打不开时返回 503，不返回旧快照。
- **未做跨进程 e2e**：测试用临时目录里的真实 SQLite 文件，没有启动 Node 写 `app-state.db`；接线后建议在真实 `AIH_HOME_DIR` 上做一次 Node 写 / Go 读的对照。
- **WebUI 未切换**：本切片不改 Node 与 WebUI；插件面板仍读 `/v0/plugins`。
- **`npm run gateway:routes` 未更新**：Go 新路由没有登记进路由清单；补清单属于 Node 侧/契约变更，留到接线提交。

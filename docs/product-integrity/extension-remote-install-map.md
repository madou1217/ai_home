- 唯一写入文件：`docs/product-integrity/extension-remote-install-map.md`。实现、其他审计文档和并行会话文件均不修改；不暂存、不提交、不建分支/worktree。
- 本轮只读取仓库源码、批准计划、README、`docs/product-integrity/web-feature-map.md` 和 Git 状态。没有运行测试、构建、CLI doctor/demo、安装、重启、SSH、API、GUI；没有读取运行日志、用户配置库、真实账号导出或凭据。
- 共享工作区不是静态快照：首次读到 HEAD `f8c7e7c4d`，写文档前 HEAD 已变为 `b1ba60e667788df04b7d37f6d7e2369ebe358b4d`，且存在大量并行修改。下述依据是**本轮实际读取的工作区文件及函数**，不能归因于单一提交。`bin/ai-home.js` 等主线修改只作为接口依赖读取，不接管修复。
- 前端叶子入口以 `web-feature-map.md` 的 T/H/E/I/L/A/X 编号为准。本文只提供其后续 backend/application/OS 链路及非 Web 入口，不复制 UI 操作表；同一后端操作被多个入口复用时只登记一次。
- 原始设计链接若在当前检出中不存在，不假称已读。例如 README 引用的插件设计与备份设计，本文只使用实际可读的 README 合同、批准计划和实现注释恢复初衷。
- 全表运行证据统一为 **U：runtime unverified**。`S` 表示读取到了调用链或防线；`G01–G11` 表示下节列出的高置信源码缺口；`L` 表示显式能力限制而非缺陷。它们均不表示真实操作通过。
- 风险：`R` 只读数据；`W` 持久化；`X` 子进程/网络/系统动作；`$` 可能费用。名称为 list/status/doctor/dry-run 的入口也可能探测、建立连接或写 TOFU 记录，不能据名称在本轮执行。
- 基线：未采集性能、资源、费用、真机版本和成功率，不估算完成比例。所有条目处于“初衷/链路审查，待真实复现或验证”；后续验证 V01–V09 是申请授权后的方案，不是本次操作授权。
